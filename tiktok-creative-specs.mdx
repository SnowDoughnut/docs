TikTok paid placements. Current as of 28 July 2026.

## Video placements

| Format | Ratio and minimum | Duration | File |
| :-- | :-- | :-- | :-- |
| **In-Feed (non-Spark)** | 9:16 min 540 × 960 · 16:9 min 960 × 540 · 1:1 min 640 × 640 | Up to 10 minutes | MP4, MOV, MPEG, 3GP, AVI. Max 500 MB. Min bitrate 516 kbps |
| **Spark Ads (pull)** | Uses the existing organic video | As published organically | MP4 or MOV |
| **TopView** | 9:16, min 540 × 960 | 5–60 s, **9–15 s recommended** | MP4, MOV, MPEG, 3GP. Max 500 MB. Min bitrate 2,500 kbps |

Build vertical at **1080 × 1920**. The figures above are minimums, not targets.

<Warning>
  TopView creative requires pre-approval. Build the schedule around that rather than discovering it at launch.
</Warning>

## Carousel

| Property | Spec |
| :-- | :-- |
| Images | Upload 2–35; TikTok displays 2–20 |
| Format | JPG, JPEG, PNG |
| File size | 100 KB or less per image suggested |
| Landscape | 1200 × 628 |
| Square | 640 × 640 |
| Vertical | 720 × 1280 |
| Music | **Required**, minimum 2 seconds |
| Copy | One caption, CTA, and URL across all images |

## Copy limits

| Field | Limit |
| :-- | :-- |
| Caption (TopView, non-Spark and Spark push) | 100 characters |
| Caption lines shown (Spark) | 4 before truncation |
| Account name | 20 Latin characters |

Captions render in TikTok's standard white font. They do **not** support clickable links, @ mentions, or hashtags.

## Working notes

- **Vertical first.** 9:16 is the native experience; landscape and square are fallbacks.
- **Music is not optional on carousel.** A carousel without a track will not run.
- **Watch the carousel file size.** 100 KB per image is tight; compress deliberately rather than letting an export tool decide.
