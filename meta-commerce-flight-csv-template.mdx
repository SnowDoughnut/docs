Use this template for a catalog of bookable flights, used with Meta's dynamic ads for travel. If you're listing ecommerce products, hotels, vehicles, destinations, or real estate instead, see the [Meta Commerce catalog templates](/meta-commerce-overview) overview for the matching type.

<Warning>
  This template is partial. It covers the fields Meta generates a flight's ID from and the general shape of a flight record. Meta holds the authoritative, complete column list for this vertical, so check the full required and optional field list against [Meta's flight catalog documentation](https://www.facebook.com/business/help/120987771906806) before building a production feed.
</Warning>

<Note>
  This isn't legal advice. Confirm fare and availability accuracy with your legal or compliance team before publishing a flight catalog.
</Note>

## File format

- CSV, TSV, RSS XML, or ATOM XML, one row per flight (or per origin-destination-date combination), with a header row naming each column.
- All column headers must be in US English.
- Unlike the other five catalog types, flights don't have a dedicated ID column. Meta generates the ID automatically from the origin and destination airport codes.

## Format rules

- `price` follows the pattern used across every Meta catalog type: a number plus a three-letter ISO 4217 currency code.
- Dates are typically expected in `YYYY-MM-DD`; confirm against the current template before a first upload, since Meta's exact date format expectations weren't independently verifiable for this page.

## Data and compliance rules

<Warning>
  - Fares and availability need to match what's actually bookable at the point of click. Airline advertising is also subject to country-specific consumer protection and pricing-disclosure rules (in the US, DOT full-fare advertising rules for air travel); treat that as a separate legal obligation from Meta's own feed accuracy requirement.
  - Meta's general advertising standards, including its prohibitions on deceptive or misleading claims, apply to flight listings the same as any other catalog.
</Warning>
