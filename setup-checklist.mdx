Work through this alongside the [get started](/overview) path. A stage is done when the document is filled in, saved where your team agreed, and linked from the places that depend on it.

<Note>
  Stages 1 to 4 are the minimum before your first campaign goes live. Stages 5 to 8 can follow, but each one is a gap in what you can measure until it's done.
</Note>

## Stage 0: Locations agreed

- Filled-in workbooks have one agreed home, recorded in [get started](/overview).
- Source and creative files have one agreed home, recorded in [brand assets](/brand-assets).
- Each location has a named owner.

## Stage 1: Shared vocabulary

- [Glossary](/glossary) read by everyone who will write or review.
- [Naming conventions overview](/naming-conventions-overview) read before any convention is set.

## Stage 2: Brand

| Document | Filled in | Saved | Linked from |
| :-- | :-- | :-- | :-- |
| [Brand overview](/brand-overview) |  |  | Positioning, customer profiles, search theme briefs |
| [Positioning](/positioning) |  |  | Messaging, campaign briefs |
| [Messaging](/messaging) |  |  | Copy briefs, campaign briefs |
| [Brand voice and tone](/brand-voice-and-tone) |  |  | Copy briefs, article briefs |
| [Visual identity](/visual-identity) |  |  | Creative briefs, landing page briefs |
| [Logo usage](/logo-usage) |  |  | Creative briefs |
| [Brand assets](/brand-assets) |  |  | Creative briefs, all production |

- Every line in the brand overview traces back to a person or a page.
- Positioning is settled before messaging is written.
- Every claim in messaging has evidence and a refresh date.
- The asset register names an owner and a review date for every asset.

## Stage 3: Product catalog

| Document | Filled in | Saved | Linked from |
| :-- | :-- | :-- | :-- |
| [Product catalog](/product-catalog) |  |  | Campaign naming, campaign briefs |

- Every product you advertise has a row and a short identifier.
- Every identifier is registered before any campaign brief references it.
- Retired products keep their row and their identifier.
- Offers are listed separately from products, with terms and an expiry.

- Every field in every pattern has a closed list of allowed values.
- Someone owns adding new values to those lists.

## Stage 5: Tracking

- [UTM standards](/utm-standards) filled in, with a closed list per parameter.
- [Event tracking plan](/event-tracking-plan) built using the stage 4 event convention.
- Tracking plan saved to the [event library](/event-tracking-plan-overview).
- UTM values match the campaign naming values, so platform and analytics data can be joined.

## Stage 6: Customer profiles

- At least one profile filled in from the [B2B](/customer-profile-brief) or [B2C](/b2-c-customer-profiles) brief.
- Each profile named with the stage 4 convention.
- Each profile saved to the [customer profile library](/customer-profile-library-overview).
- Platform audience CSVs exported where needed: [Meta](/customer-profile-csv-template-meta), [Google](/customer-profile-csv-template-google), [LinkedIn](/customer-profile-csv-template-linkedin), [TikTok](/customer-profile-csv-template-tiktok).

## Stage 7: Reporting

- [Marketing reporting data dictionary](/marketing-reporting-data-dictionary) filled in: every metric has one definition and one owner.
- [KPI definitions](/kpi-definitions) agreed, including the north star and its counter-metric.
- [Reporting cadence](/reporting-cadence) set: who reports what, to whom, how often.
- [Dashboard standards](/dashboard-standards) agreed.
- [Flat file](/flat-file-template) built, and every report reads from it rather than from the platforms directly.

## Stage 8: Experiments

- [Experiment ID](/experiment-id-convention) pattern defined.
- The register for issued IDs has a home and an owner.
- [Experiment brief](/experiment-brief) template ready to copy.
- [Pilot brief](/pilot-brief) template ready to copy, for spend with no control.

## Setup is complete when

- Someone new can find the answer to "what do I call this?" without asking.
- A campaign brief links to a positioning statement, a customer profile, and a naming convention that all already exist.
- A weekly report can be produced from the flat file without anyone opening an ad platform.
- Nothing above lives in two places.
