A call-to-action button is the fixed label a platform puts on an ad, chosen from the platform's own list. The copy can say anything; the button can only say what the platform allows. This page holds each platform's list. Checked 30 October 2026.

The button should promise the same next step the landing page delivers. "Shop now" on a page with no products, or "Book now" on a page with no booking, breaks the ad's promise in its last word.

The MCP ranks each list against the context of the ad using the [context facets](/mcp-registry#context-facets) and offers the five that fit best. Rows with no Best for rank last, in the order shown.

**Lead ads** offer a shorter list: Apply now, Download, Get quote, Learn more, Sign up, and Subscribe. Messaging buttons need a messaging destination.

<Note>
  Meta's labels here are converted from its Marketing API values, because the help page that lists the on-screen labels could not be checked. Confirm the wording in Ads Manager the first time a button is used.
</Note>
