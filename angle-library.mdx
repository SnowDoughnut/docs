One row per angle. An angle is not in production until it has a row here.

The library exists to answer a question no individual brief can: across everything running right now, how many different arguments are actually in market. An account with twenty creatives and one argument has a diversity problem that only shows up when the angles are listed side by side.

<Info>
  Rows are filled from a completed [angle brief](/angle-brief). Type values come from the [message angle dictionary](/ad-name-conventions#message-angle) in the ad naming conventions, which is what a report groups by.
</Info>

## Before you add an angle

<Steps>
  <Step title="Read the register below">
    If an angle already makes this argument, add a hook to it rather than creating a second entry.
  </Step>
  <Step title="Check the coverage tables">
    A gap is a better reason to write a new angle than an idea that arrived on its own.
  </Step>
  <Step title="Fill in the brief, then add a row">
    A row with no brief behind it is a name, not an angle.
  </Step>
</Steps>

## Status values

| Status | Meaning |
| :-- | :-- |
| Draft | Brief written, nothing produced |
| Testing | In market, before its read date |
| Live | Proven and in rotation |
| Resting | Paused deliberately, expected back. Note when |
| Retired | Stopped. Note the date and what it lost to |

<Note>
  Retired rows stay in the library, with the reason. An angle that was tried and failed is the most useful row here, because it is the one that stops the same argument being proposed again next quarter as a fresh idea.
</Note>

## Review

Angles decline without announcing it, so the review is scheduled rather than triggered.

At each review, for every live angle:

- Is performance falling across every execution, or only in one? Across all of them points at the argument. In one points at the creative. See [angle fatigue is not creative fatigue](/angle-concepts#angle-fatigue-is-not-creative-fatigue).
- Are the proof points still current, and still cleared?
- Has the angle drifted past its guardrails in any live execution?
- Do the coverage tables still show more than one argument carrying the account?

<Warning>
  Producing more creative against a declining angle is the most expensive response available, because it looks like work and answers a question the data already settled. Check whether the argument is tired before scheduling the next shoot.
</Warning>
