A copy template is where finished words get written to a format's field structure and character limits. It is the last step before setup, and it is per format rather than per campaign.

Two documents sit above every template on this page, and neither is replaced by it:

| Document | What it carries |
| :-- | :-- |
| [Copy brief](/copy-brief) | The objective, reader, message, proof, mandatories, and approved claims |
| [Copy brief concepts](/copy-brief-concepts) | The reasoning behind each section of that brief |

<Note>
  One filled template is one ad. An ad group running three ads means three filled templates, each named per the [ad naming conventions](/ad-name-conventions) and filed in the [copy drive](/copy-drive). Templates that carry a variant block also mark which of them is the control.
</Note>

| Format | Template |

One template covers every organic platform, because the fields are the same and only the limits change. It carries the caption, hashtag, and alt text ceilings per platform, the truncation point that matters more than the ceiling, and which link placements are actually clickable where.

## Website and landing pages

| Format | Template |
| :-- | :-- |
| Any page on your own site | [Landing page block library](/landing-page-skeleton) |

The block library is the web equivalent of a copy template: it holds the field structure per block (hero headline, subhead, button, section headings) and the [length guidance](/landing-page-skeleton#copy-lengths) for each. It is one document rather than two because the blocks already define the fields, and a second list of them would be a second thing to keep in step.

Web lengths are house guidance rather than platform limits, since no page truncates a headline at a fixed count. What constrains them is the type scale in [visual identity](/visual-identity) and how the line wraps on a small screen.

## Where character limits live

Limits sit in the template for the format, and nowhere else. A second copy in a brief or a checklist is one more place for a number to go stale when a platform changes a field. For web, the [block library](/landing-page-skeleton#copy-lengths) is that template.

The same rule applies to creative dimensions, which live in [image and video specs](/image-and-video-specs) and the per-platform spec pages rather than in these templates. A copy template covers words; a spec page covers files.
