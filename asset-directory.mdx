## What belongs where

Two questions decide where an asset goes: what kind of file it is, and whether it is finished.

| Asset | Goes in |
| :-- | :-- |
| A finished, approved image or static ad | [Creative drive](/creative-drive) |
| A finished, approved video or its source files | [Video drive](/video-drive) |
| Approved copy that has run, in any channel | [Copy drive](/copy-drive) |
| An account list, customer match file, or suppression list | [Audience list store](/audience-list-store) |
| A published landing page | [Landing page library](/landing-page-library) |
| Logos, fonts, color files, brand templates | [Brand assets](/brand-assets) |
| A completed brief of any kind | Its own brief library |

<Warning>
  Drafts and works in progress stay in the project folder they were made in. The drives hold approved assets, so that anyone pulling from them can use what they find without checking whether it was signed off.
</Warning>

## Working with the drives

<Steps>
  <Step title="Search before you brief">
    Check the relevant drive first. Reusing an approved asset skips both production time and review.
  </Step>
  <Step title="Name it before you upload">
    Every file follows the [file naming conventions](/file-naming-conventions). An asset saved under a name only its maker understands is not findable by anyone else.
  </Step>
  <Step title="Version, don't overwrite">
    Save a new version rather than editing over the old one, so the history stays intact.
  </Step>
  <Step title="Link it back to its brief">
    An asset should be traceable to the brief that produced it, and the brief should link to the finished asset.
  </Step>
</Steps>
