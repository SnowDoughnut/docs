A framework is the order the copy makes its argument in. The [hook](/hook-types) opens the ad; the framework carries it from that opening line to the call to action. One framework per asset. Mixing two produces copy that restarts in the middle.

Record the pick in the [copy brief](/copy-brief) so variants stay comparable: two ads on the same framework with different hooks test the hook, and the reverse tests the framework.

## Four-part

**Hook → Problem → Proof → Push.** Open, name what the reader is stuck on, show the evidence, tell them what to do.

Use it as the default for cold-audience primary text: it fits in four short lines and nothing in it assumes the reader knows the product.

> Still counting trays by hand?
> Every hand count is a batch you could have sold.
> Doughnut Labs bakeries cut batch waste 38% in eight weeks.
> Book a demo.

## Problem and solution

**Problem → Agitate → Solve.** Name the pain, make its cost concrete, then show the way out.

Use it when the reader already feels the problem and the job is making it urgent enough to act on. Strongest for pains with a hidden cost.

> Your bakers spend Friday rebuilding the production sheet.
> That is four hours a week, every week, on a document nobody reads twice.
> Doughnut Labs builds it from your orders overnight.

## Before and after

**Before → After → Bridge.** The current state, the better state, and the product as the path between them.

Use it when the transformation is easy to picture. It works in copy the same way it works in creative, which makes it a natural pair for before-and-after imagery.

> Monday: six spreadsheets and a whiteboard.
> Monday with Doughnut Labs: one dashboard, loaded before you arrive.
> Switching takes an afternoon.

## AIDA

**Attention → Interest → Desire → Action.** The long-form classic: earn the read, build the case, make them want it, close.

Use it where there is room to build: email body copy, landing pages, and lead ad Instant Forms. In a 125-character primary text it collapses into four-part, so reach for it when the format gives the argument space.

## Feature to benefit

**Feature → What it does → What that means for you.** Each line walks one feature out to the difference it makes.

Use it for warm audiences and retargeting, where the reader knows the product and is weighing specifics. It is the one framework that works as a list, one feature per line.

> Overnight production sheets. Your Friday afternoon back.
> Live tray counts. No more walk-the-floor stock checks.

## Direct offer

**Offer → Terms → Call to action.** The offer is the hook, the terms are the body, the CTA is the close.

Use it for promotions and retargeting when the product needs no introduction. Everything a [value, urgency, or scarcity hook](/hook-types) claims here has to be literally true, which is why this framework leans hardest on [legal review](/legal-review-process).

> 20% off your first quarter of Doughnut Labs.
> New accounts, through Friday.
> Claim it.

## Picking one

| Situation | Framework |
| :-- | :-- |
| Cold audience, short format | Four-part |
| The reader already feels the pain | Problem and solution |
| The transformation is easy to picture | Before and after |
| Long format with room to build | AIDA |
| Warm audience weighing specifics | Feature to benefit |
| Promotion or retargeting with an offer | Direct offer |

## When each framework fits

The MCP ranks this list against the context of the asset and offers the five that fit best, using the [context facets](/mcp-registry#context-facets). A framework whose Avoid when matches is left out.

| Framework | Best for | Avoid when |
| :-- | :-- | :-- |
| Four-part | audience: cold; length: short; goal: consideration, conversion | length: long |
| Problem and solution | audience: warm; goal: consideration | audience: customers |
| Before and after | goal: awareness, consideration; channel: meta, tiktok, organic-social |  |
| AIDA | length: long; channel: email, web | length: short |
| Feature to benefit | audience: warm, retargeting, customers; goal: consideration | audience: cold |
| Direct offer | offer: sale, trial, launch; audience: warm, retargeting, customers | offer: evergreen; audience: cold |

A new framework is a new section above and a new row here. It joins the ranking the moment it is published.
