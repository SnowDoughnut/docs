The MCP starts every request here. It matches what you asked against the requests below, opens the page in **Start at**, and runs that page's wiring: the questions in order, the pages it pulls, and the output. A request that matches more than one row gets one short question back: which of the matches you meant.

Matching is by meaning, not exact wording. "Can you help me write some Meta ads" routes the same as "Help me write Meta copy".

When a request matches nothing, the MCP searches the [registry](/mcp-registry) for a key that fits, and says so if the framework does not cover it yet.
