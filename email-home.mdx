## Tagging email sends

Email traffic has to appear in the same [flat file](/flat-file-template) as everything else, which means it needs the same tags.

| Parameter | Value comes from |
| :-- | :-- |
| `utm_source` | [UTM standards](/utm-standards), the closed list |
| `utm_medium` | Usually `email`, set in your standard |
| `utm_campaign` | The campaign name from [campaign naming conventions](/campaign-naming-conventions) |

Untagged email links are the most common reason a channel looks smaller in reporting than it actually is.
