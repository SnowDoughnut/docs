## Theme

Copy these across from the [search theme brief](/google-search-theme-brief) for the ad group this ad runs in. They are the constraints the headlines below are written against, and having them on the same page is what stops an ad being written to the campaign in general rather than to this theme.

| Field | Fill in |
| :-- | :-- |
| Theme name and short form | _E.g. Reporting automation,_ `REPORTAUTO` |
| The intent, in one sentence | _E.g. Find a way to stop building the same weekly report by hand_ |
| Theme phrase to appear in headlines | _E.g. "weekly report"_ |
| Angle this theme takes | _E.g. Time saved, not features_ |
| What the ads must not claim | _E.g. "Instant setup". Legal has not cleared it_ |
| Landing page, and the promise it carries | _E.g._ `/lp/reporting-automation`_. Your weekly report builds itself_ |

<Note>
  Every keyword in the theme should be served by the ad you are about to write. If a headline that suits one keyword would be wrong for another, the theme is holding two intents and wants splitting before the copy is written. See [the one-ad test](/google-search-theme-concepts#the-one-ad-test-decides-the-boundary).
</Note>

<Warning>
  A headline test only measures what you pinned. A responsive search ad assembles its own combinations, so an unpinned test headline may not serve at all in one variant and may dominate in another, and the result then reflects the auction rather than the headline. Pin the field under test to the same position in every variant, and change nothing else. Record the pins below.
</Warning>

## Pinning

| Field | Pinned to | Why |
| :-- | :-- | :-- |
| _E.g. Headline 1_ | _E.g. Position 1_ | _E.g. The variable under test in `TEST07`_ |
| _E.g. Headline 3_ | _E.g. Position 2_ | _E.g. "No card required", required by [legal review](/legal-review-process) 12 Apr_ |
| \[add pin\] |  |  |

Unpinned fields rotate freely. Pinning narrows the combinations Google can test, which usually lowers ad strength; that trade is deliberate when a claim is required or a variable is under test, and worth writing down so the next person doesn't remove the pin to lift the rating.

A theme phrase is the third case. If the theme depends on a specific phrase reaching the searcher, writing it into one headline only puts it in the pool that might be shown. Pin it, or accept that some serves will not carry it.
