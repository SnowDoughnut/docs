A hook framework is a sentence pattern with slots. It turns a [hook type](/hook-types), the family of opening, into a line someone can say in the first two seconds. The same line usually runs twice: spoken by the creator and as the text on screen, paired with one of the [visual hooks](/visual-hooks).

Every framework here does the same two jobs: **say who the ad is for, and name the problem they have.** Keep it that simple. A plain call-out gets exactly the right people watching; a clever one gets the wrong people, or no one.

Fill the slots from the [customer profile](/b2-c-customer-profiles) and [messaging](/messaging). A slot is a specific word, in the audience's own terms: "if you're a roofer", not "if you work in home services".

## The frameworks

| # | Framework | Fill in | Example | Hook type |
| :-- | :-- | :-- | :-- | :-- |
| 1 | If you're **X**, pay attention | X = who this is for, as they would describe themselves | "If you're a roofer, pay attention." | Problem call-out |
| 2 | Most **X** are **Y** because | X = the audience, Y = the pain they share | "Most roofers are stuck with low-quality leads because of this." | Problem call-out |
| 3 | The reason you **X** is | X = a problem the viewer already has | "The reason you can't close a deal over the phone is this." | Problem call-out |
| 4 | **X!** | X = the audience, named in one or two words | "Roofers!" | Problem call-out |
| 5 | **X** is **Y** | X = what the audience does, Y = how it feels to them | "Roofing is hard." | Problem call-out |

The list, and the roofer and salesperson examples, come from a short-form breakdown of the best hooks for Facebook ads.

## How each one works

| Framework | What it does | Watch for |
| :-- | :-- | :-- |
| If you're X, pay attention | Names the audience outright, so only the right people keep watching. No fancy call-out needed | An X so broad it names everyone, which names no one |
| Most X are Y because | Names the audience and the pain point in one line, and promises the reason | Y has to be true and backed by the approved claims |
| The reason you X is | Skips the audience and speaks straight to a problem they have, which stops them mid-scroll | The reason given in the next line has to be what the product fixes, or the ad breaks its promise |
| X! | The shortest call-out there is: shout the audience's name | Needs energy in delivery and a visual hook behind it; read flat, it is just a word |
| X is Y | Says out loud what the audience feels about their own work | The most open to creativity; keep Y in their words, not the brand's |

## When each one fits

The MCP ranks this list against the context of the ad and offers the ones that fit best (four in a dialog, five in chat), using the [context facets](/mcp-registry#context-facets). A framework whose Avoid when matches is left out.

| Framework | Best for | Avoid when |
| :-- | :-- | :-- |
| If you're X, pay attention | audience: cold; goal: awareness, consideration; business: b2b, local, sales-led | audience: customers |
| Most X are Y because | audience: cold; goal: consideration; business: b2b, local, sales-led |  |
| The reason you X is | goal: consideration, conversion; audience: cold, warm |  |
| X! | length: short; audience: cold; channel: meta, tiktok |  |
| X is Y | goal: awareness; audience: cold; length: short |  |

A new framework is a new row in every table. It joins the ranking the moment it is published.

## Writing one

- **Who, then the problem.** If the line does not say who it is for or what hurts, it is not a hook yet.
- **Write it to fit the platform.** On Meta the line has to land before the "See more" fold, about 125 characters; on TikTok it is the 100-character caption. Every example above is under 70.
- **One framework per ad.** Hook variants are the same script opened with different frameworks, so a test shows which opening did the work. Test them in your next batch.
- **The next line pays it off.** Every framework opens a question. The second line answers it, or the viewer feels baited and leaves.
- **Spoken and on screen match.** The text on screen can be shorter than the spoken line, but it says the same thing.
- **The claim has to be true.** A "most X are Y" is a claim, and stays inside the approved claims table in [messaging](/messaging).
