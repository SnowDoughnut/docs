Each template below is a blank sheet you copy and fill in. The briefs and concepts pages at the bottom hold the reasoning behind what goes in them.

Start from your campaign type. [Google](/google-home) maps each type to its copy template and creative specs in one table.

## Copy templates

One filled template is one ad. Each holds the field structure and character limits for a single campaign type; the words come from the [copy brief](/copy-brief).

| Campaign type | Template |
| :-- | :-- |
| Search | [Google Search copy template](/google-search-copy-template) |
| Performance Max | [Google Performance Max copy template](/google-pmax-copy-template) |
| Demand Gen | [Google Demand Gen copy template](/google-demand-gen-copy-template) |
| Display | [Google Display copy template](/google-display-copy-template) |
| YouTube | [Google YouTube ad copy template](/google-youtube-copy-template) |
| App | [Google App campaign copy template](/google-app-campaign-copy-template) |

## Search themes

| Template | Use it for |
| :-- | :-- |
| [Search theme template](/google-search-theme-template) | One theme, which becomes one ad group. Copy it per theme once the reasoning is familiar. |

Use the [search theme brief](/google-search-theme-brief) instead if you want the same structure with a concept review on every section, and file the finished sheet in the [search theme register](/google-search-theme-register).

## Feeds and data files

| Feed | Template |
| :-- | :-- |
| Page feed, for Dynamic Search Ads and Performance Max landing pages | [Page feed CSV template (Google Ads)](/google-ads-page-feed-csv-template) |
| Products, the foundation Merchant Center feed | [Product feed CSV](/google-merchant-center-product-csv-template) |
| Local inventory, extends Products | [Local inventory CSV](/google-merchant-center-local-inventory-csv-template) |
| Promotions, extends Products | [Promotions CSV](/google-merchant-center-promotions-csv-template) |
| Vehicle ads | [Vehicle ads CSV](/google-merchant-center-vehicle-csv-template) |
| Hotel properties, a separate Google product | [Hotel Center CSV](/google-hotel-center-csv-template) |

Read [Google Merchant Center feed templates](/google-merchant-center-overview) before building any of the first four. Two of them do nothing without a primary Products feed in place.

## Not templates

These get filled in too. They hold the decisions and the checks, and the templates above hold the finished artifact:

- [Google campaign brief](/google-campaign-brief) The campaign's decisions, fixed before anything is built.
- [Google pre-launch checklist](/google-pre-launch-checklist) The last pass with the campaign built and paused.
- [Google campaign process](/google-campaign-process) The order the work happens in.
- [Creative specs](/google-pmax-creative-specs) Asset dimensions and file requirements, which a copy template doesn't carry.
