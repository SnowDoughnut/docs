Google covers Search, Performance Max, Demand Gen, Display, YouTube, and app campaigns. Only the platform-specific detail lives here. Strategy, naming, tracking, and brand rules are shared.

Account setup, billing, MCC structure, conversion tag installation, keyword research, and auto-applied recommendations sit outside this knowledge base. See [what this framework covers](/what-this-framework-covers).

## Start with your campaign type

Campaign type is the largest decision in the brief: it sets which assets you need, which copy template applies, and how the campaign is structured. Find your type, then work across the row.

| Campaign type | Use it for | Copy template | Creative specs |
| :-- | :-- | :-- | :-- |
| **Search** | Demand that already exists as queries | [Search copy template](/google-search-copy-template) | [Responsive search ads](/google-search-demandgen-display-specs#responsive-search-ads). Text only, no images needed |
| **Performance Max** | One budget across every Google surface | [PMax copy template](/google-pmax-copy-template) | [Performance Max specs](/google-pmax-creative-specs) |
| **Demand Gen** | Visual demand creation before the search | [Demand Gen copy template](/google-demand-gen-copy-template) | [Demand Gen specs](/google-search-demandgen-display-specs#demand-gen) |
| **Shopping** | A retail catalog, fed by [Merchant Center](/google-merchant-center-overview) | Feed-driven, no copy template | [Product feed template](/google-merchant-center-product-csv-template) |
| **Video** | Reach and consideration on YouTube | [YouTube copy template](/google-youtube-copy-template) | [YouTube specs](/youtube-creative-specs) |
| **App** | Installs and in-app events | [App copy template](/google-app-campaign-copy-template) | [Performance Max specs](/google-pmax-creative-specs) for asset ratios |
| **Display** (responsive) | Being migrated into Demand Gen | [Display copy template](/google-display-copy-template) | [Display specs](/google-display-creative-specs) |

Every type uses the same three documents: the [process](/google-campaign-process), the [brief](/google-campaign-brief), and the [pre-launch checklist](/google-pre-launch-checklist). The type changes which assets and template you need, not the order of the work.

<Warning>
  Don't brief a new standalone Display campaign. Google began migrating Display into Demand Gen in June 2026 and is phasing out new standalone Display campaigns. Brief visual campaigns as Demand Gen; responsive display assets still follow the [Display specs](/google-display-creative-specs).
</Warning>

## Search themes

On Search, a campaign is organized around themes rather than around individual keywords. A theme is one search intent held together as a single unit: the queries that express it, the customer profile behind them, the landing page they go to, and the ads written to match. It becomes one ad group.

| Document | Use it for |
| :-- | :-- |
| [**Search theme concepts**](/google-search-theme-concepts) | Why themes replaced single-keyword ad groups, and what decides where one theme ends |
| [**Search theme brief**](/google-search-theme-brief) | The workbook for one theme, with a concept review on every section |
| [**Search theme template**](/google-search-theme-template) | The blank sheet to copy per theme once the reasoning is familiar |
| [**Search theme register**](/google-search-theme-register) | Every live theme in one table, checked before a new one is planned |
| [**Glossary**](/glossary#search-theme) | Definitions, including how our search themes differ from Google's Performance Max field of the same name |

<Warning>
  A search theme in this framework is not the same as **search themes** in Performance Max, which is a field inside an asset group. See the [glossary entry](/glossary#search-themes-performance-max) for both definitions.
</Warning>
