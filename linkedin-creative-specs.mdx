| Ratio | Recommended | Minimum |
| :-- | :-- | :-- |
| Landscape **1.91:1** | 1200 × 628 | 640 × 360 |
| Square **1:1** | 1200 × 1200 | 360 × 360 |
| Portrait **4:5** | 720 × 900 | 360 × 640 |

JPG, PNG, or GIF. Maximum **5 MB**. Animated GIFs: no more than 250 frames. Destination URL up to 2,000 characters.

Portrait serves on mobile, so include it if your audience skews mobile.

## Video

| Orientation | Build at |
| :-- | :-- |
| Landscape 16:9 | 1920 × 1080 or 1200 × 675 |
| Portrait 4:5 | 720 × 900 |
| Vertical 9:16 | 720 × 1280 |
| Square 1:1 | Supported |

MP4. **75 KB to 500 MB.** Duration 3 seconds to 30 minutes, with **15–30 seconds recommended** for the broadest placement eligibility. SRT caption files are supported.

## Carousel

| Property | Spec |
| :-- | :-- |
| Cards | 2–10 |
| Recommended | 1080 × 1080 (1:1) |
| File | JPG, PNG, or non-animated GIF. Max 10 MB per card |
| Video cards | Not supported |

Each card can point at a different destination URL, which makes carousel useful for a multi-product or multi-offer set.

## Copy limits

<Note>
  LinkedIn's "recommended" counts are **truncation** guidelines — the point at which text gets cut off in the feed. The input maximums are considerably longer. Write to the recommended figure; treat the maximum as headroom, not a target.
</Note>

| Field | Recommended | Maximum |
| :-- | :-- | :-- |
| Introductory text (single image, video) | 150 | 3,000 |
| Introductory text (carousel) | 150 | 255 |
| Headline (single image, video) | 70 | 200 |
| Description (single image) | 100 | 300 |
| Card headline (carousel) | — | 45 |
