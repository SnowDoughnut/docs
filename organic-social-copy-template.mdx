Fill in one copy per post. The strategy comes from the [organic social post brief](/organic-social-post-brief); this template is where the words get written to the limits the platform enforces.

<Note>
  Write to the limit, not past it. Copy written loose and cut down afterward tends to lose the part that was doing the work, and on organic the first line is doing most of it.
</Note>

## Character limits

Current as of 10 August 2026. Platforms change these without notice, so confirm in the app before relying on a number near the edge.

| Platform | Caption | Truncates after roughly | Hashtags | Alt text |
| :-- | :-- | :-- | :-- | :-- |
| Instagram feed | 2,200 | 125 characters | 30 max | 100 |
| Instagram Reels | 2,200 | 1 to 2 lines | 30 max | Not available |
| LinkedIn | 3,000 | 140 to 210 characters | No hard cap, 3 to 5 usual | 300 |
| Facebook | 63,206 | 125 characters | No hard cap | 1,000 |
| TikTok | 2,200 | 1 to 2 lines | Counted inside the caption limit | Not available |
| X | 280 | Not truncated | Counted inside the limit | 1,000 |
| YouTube Shorts | 100 title, 5,000 description | Title truncates in feed | Counted inside the description | Not available |
| Threads | 500 | Not truncated | 1 topic tag | 1,000 |

<Warning>
  The truncation point matters more than the ceiling. A 2,200 character Instagram caption is legal and almost none of it is read: everything after roughly 125 characters sits behind **more**. Write the hook to land above that line and treat the rest as optional depth.
</Warning>

## Hashtags

| Field | Fill in |
| :-- | :-- |
| How many | _E.g. Three topical, no branded tag_ |
| Where they go | _E.g. End of the caption, not the first comment_ |
| Which are approved | _E.g. From the brand's tag list, not invented per post_ |

Hashtag counts near a platform's maximum tend to read as spam to both the reader and the ranking system. The limit in the table is what the platform accepts, not a target.

## Link placement

Not every platform makes a link clickable, and the framework's [tagging rule](/utm-standards) can only be satisfied where one is.

| Platform | Clickable options | Not clickable |
| :-- | :-- | :-- |
| Instagram | Bio link, Story link sticker, or a link in a Reel if available to the account | Feed caption, first comment |
| LinkedIn | Caption, first comment | |
| Facebook | Caption, first comment | |
| TikTok | Bio link, or in-caption where the account has the feature | Comments |
| X | Caption | |
| YouTube | Description, pinned comment | |

<Warning>
  On Instagram neither the caption nor the first comment is clickable, so "link in the caption" is not an available answer. The real choices are the bio link and a Story link sticker. Whichever you pick still carries [UTMs](/utm-standards), or the traffic arrives as direct and the channel looks like it does nothing.
</Warning>

## Accessibility

- Alt text for every image or carousel card, written for someone who cannot see it rather than restating the caption.
- Captions burned into video, or platform captions enabled, since most feed video plays muted.
- Hashtags in `CamelCase` when a tag runs several words together, so screen readers can separate them.
