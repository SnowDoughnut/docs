Read this before requesting ad account access. Everything here is a convention the team already decided, so following it is not a preference.

<Steps>
  <Step title="1. Naming">
    Read the [naming conventions overview](/naming-conventions-overview), then the three that apply to every build: [campaign](/campaign-naming-conventions), [ad set, ad group and variant](/ad-set-group-naming-conventions), and [ad](/ad-name-conventions).

    Names are set at build time. Renaming later breaks the join between platform spend and analytics.
  </Step>
  <Step title="2. Tracking">
    Read [UTM parameters](/utm-parameters) for what the tags do, then the team's [UTM standards](/utm-standards) for the actual allowed values. The `utm_campaign` value has to match the campaign name.
  </Step>
  <Step title="3. Who you're targeting">
    Read [customer profile naming conventions](/customer-profile-naming-conventions) and browse the [customer profile library](/customer-profile-library-overview). Campaigns target a profile that already exists, by name.
  </Step>
  <Step title="4. How a campaign gets briefed">
    Read the [marketing campaign brief](/marketing-campaign-brief) and the [campaign brief process](/campaign-brief-process). No campaign is built without a brief.
  </Step>
  <Step title="5. The platform you'll work in">
    [Meta](/meta-home), [Google](/google-home), [LinkedIn](/linked-in-home), or [TikTok](/tik-tok-home). Each page holds the creative specs, copy templates, and audience file formats for that platform.
  </Step>
</Steps>

## What's expected every time

| Every campaign | Reference |
| :-- | :-- |
| Has a filled brief before it's built | [Marketing campaign brief](/marketing-campaign-brief) |
| Is named to convention at build time | [Name something](/name-something) |
| Has every link tagged | [UTM standards](/utm-standards) |
| Targets a profile from the library | [Customer profile library](/customer-profile-library-overview) |
| Passes QA and launch checks | [Campaign QA](/campaign-qa-checklist), [launch checklist](/campaign-launch-checklist) |
| Is filed when it ends | [Campaigns library](/campaign-library-overview) |

## Your first campaign

Follow [make a campaign](/make-a-campaign) end to end. It sequences all of the above and tells you where each output gets saved.
