The brand is defined across six workbooks. Each one covers a different layer, and none of them repeats another. Start here to find the right one.

## The documents

| Document | Defines | Fill it in when |
| :-- | :-- | :-- |
| [Positioning](/positioning) | Who the brand is for, what it competes against, what makes it different, and the evidence behind that | First. Everything else depends on it |
| [Messaging](/messaging) | The approved words: value proposition, pillars, tagline, pitch, boilerplate, cleared claims | After positioning is settled |
| [Brand voice and tone](/brand-voice-and-tone) | How the brand sounds: voice traits, tone by situation, style rules, terminology | Alongside messaging |
| [Visual identity](/visual-identity) | Color, typography, layout, imagery, iconography, with exact values | Any time. Independent of the verbal work |
| [Logo usage](/logo-usage) | Variants, clear space, minimum sizes, backgrounds, misuse, co-branding | After the logo is final |
| [Brand assets](/brand-assets) | The file register, formats, access, licensing, and retirement | Last. It records what the others produced |

## Order to work in

<Steps>
  <Step title="Positioning">
    Settle the strategic claim before writing a word of copy. Messaging that ladders up to nothing has to be redone.
  </Step>
  <Step title="Messaging and voice">
    Messaging sets what the brand says. Voice sets how it sounds. They're filled in together because each one exposes gaps in the other.
  </Step>
  <Step title="Visual identity and logo">
    These can run in parallel with the verbal work. Logo usage needs a final logo, so it usually lands last of the two.
  </Step>
  <Step title="Brand assets">
    Once the other five are decided, the register catalogs the files they produced and sets the rules for using them.
  </Step>
</Steps>

## When something isn't covered

No set of guidelines anticipates every case. When a question falls outside all six documents:

1. Check whether an existing rule answers it by analogy. Most edge cases are variations on something already written down.
2. If it doesn't, take it to the brand lead through the [brand approval process](/brand-approval-process).
3. If the same question comes up twice, it belongs in one of the six documents. Add it there.

## Briefs link here, they don't restate

The brand system is the stable layer. Everything produced against it is the changing layer, and the two stay in sync only because the changing layer points at the stable one instead of copying it.

| Brief | Pulls from |
| :-- | :-- |
| [Marketing campaign brief](/marketing-campaign-brief) | Positioning, the message pillar, the customer profile |
| [Creative brief](/creative-brief) | Visual identity, logo usage, brand assets |
| [Copy brief](/copy-brief) | Messaging, the claims table, voice and tone |
| [Landing page standards](/landing-page-brief) | Messaging, visual identity, voice and tone |
| [Article brief](/article-brief) | Voice and tone, the claims table |

A brief that pastes in the positioning statement creates a second copy that drifts within a quarter, and after a year nobody can tell which version is current.

## Keeping it current

A rule changed here changes everywhere at once, which only holds if the documents stay accurate.

- **Positioning and messaging**: review annually, or when the product, the category, or the buyer changes.
- **Visual identity and logo usage**: review annually, or at a rebrand.
- **Brand assets**: review on the cadence recorded per asset in the register.
- **Voice and tone**: review annually, or when a new channel is added.
