Turns an approved angle into everything production needs: a filled [creative brief](/creative-brief), a deliverables plan built against the platform's specs, and a direction card per variant. The asset itself is made by the [creator](/glossary#creator) your team's defaults name, person or AI, and the campaign is built in your ad platform, never here.

## When it runs

Ask for ad creative in any form and this skill loads: "I need creative for the spring push", "brief the new static set", "what assets do we need for TikTok", or an [angle brief](/angle-brief) handed over with "turn this into ads".

It does not write the ad copy; the platform copy skills do that against the same angle. It does not make the finished asset either; it briefs whoever does.

## The three rules it enforces

<Steps>
  <Step title="No unbriefed creative">
    Every asset traces to a filled creative brief, and the brief's mandatories and must-not-include lists are hard limits on the work. A required legal line or a banned claim is not a note for later; it is in the brief before production starts.
  </Step>
  <Step title="Specs come from the spec pages">
    Deliverables are planned from the [master asset pack](/image-and-video-specs) and the platform's own specs page: dedicated vertical at full resolution rather than an upscaled crop, a real 16:9 edit rather than a pillarboxed vertical, and anything that must survive every crop kept inside the core the spec page draws.
  </Step>
  <Step title="Variants vary one thing">
    A variant set is different [hooks](/hook-types) on one angle, or one execution change against a control. When two directions compete, the brief's test-arm section records what is held constant, and the comparison gets a registered experiment ID before it goes live.
  </Step>
</Steps>

## What it asks you for

One question per turn, following [how the MCP talks](/mcp-conversation).

| Question | Why it needs the answer |
| :-- | :-- |
| Platform and placements | Decides the specs, the ratios, and which master assets cover them |
| Asset type | Static, video, carousel, or a mix; decides the deliverables table |
| The angle | The [angle brief](/angle-brief) carries the proposition, the drafted hooks, and the must-not-claim line |
| How many variants, split how | Hooks on one angle, or an execution test with a control |
| What already exists | Product UI, footage, photography, past assets worth reusing from the creative library |

## What you get

- The [creative brief](/creative-brief) filled: the strategic core from the campaign and angle briefs, deliverables with every attribute, mandatories and guardrails split into must-include and must-never, and the brand system linked rather than retyped.
- A deliverables table planned from the [master asset pack](/image-and-video-specs), with export sizes per placement and the required adaptations named up front.
- A direction card per variant: the hook it opens with, the visual concept, the text overlay copy, and what is held constant.
- The handoff: the [creator](/glossary#creator) your defaults table names makes the asset, the finished files land in the location the brief records under their [file names](/file-naming-conventions), and review runs the [creative review checklist](/creative-review-checklist) against this brief.

## Runbook

The run card an agent executes this skill from, in order. The turn-by-turn contract is [how the MCP talks](/mcp-conversation).

| Step | What happens |
| :-- | :-- |
| Trigger | Any request for ad creative, a creative brief, or an asset plan |
| Ask 1 | Platform and placements. Skip when the campaign brief names them |
| Ask 2 | Asset type: static, video, carousel, or a mix. Skip when the brief names it |
| Ask 3 | The angle, from the [angle library](/angle-library). Skip when attached |
| Ask 4 | Variant count and split: hooks on one angle, or an execution test. Skip when the brief set it |
| Ask 5 | What already exists: footage, UI, photography, reusable assets. Skip when the library was already searched this conversation |
| Pulls | The [creative brief](/creative-brief), the [angle brief](/angle-brief), [hook types](/hook-types), [image and video specs](/image-and-video-specs) plus the platform's own specs page, the creator defaults table in the [creative brief process](/creative-brief-process), [file naming conventions](/file-naming-conventions), and the [creative review checklist](/creative-review-checklist) |
| Rules | The three rules above |
| Output | The filled brief, the deliverables table, and one direction card per variant, delivered to the recorded location for the named creator to produce against |

One question per turn, options offered as a pick list, and nothing asked that the documents already answer.
