A template is a blank sheet you copy and fill in. Everything on this page is one of those. The briefs and concepts pages at the bottom hold the reasoning behind what goes in them.

## Page templates

| Template | Use it for |
| :-- | :-- |
| [Landing page skeleton](/landing-page-skeleton) | The structure and final copy of one page, block by block. |

The skeleton is the web equivalent of a copy template. It holds the field structure per block (hero headline, subhead, button, section headings) and the [length guidance](/landing-page-skeleton#copy-lengths) for each, so there's no second document to keep in step. [Copy templates](/copy-templates) explains why web lengths are house guidance and what actually constrains them.

## Registers

A register is a table you add a row to. Templates and registers both get filled in as part of publishing a page.

| Register | What it holds |
| :-- | :-- |
| [Landing page library](/landing-page-library) | Campaign pages, built for one offer and retired with it. |
| [Site pages register](/site-pages-register) | Standing pages: homepage, pricing, product, contact. |

Both carry an owner, a conversion action, a review date, and a record of what points at them. Check the library before briefing a new build; an existing page that fits beats a new one.
