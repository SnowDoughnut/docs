The creative drive holds finished, approved static creative: images, static ads, display banners, social graphics, and illustrations.

Check here before briefing new creative. An approved asset that already fits, or crops to fit, skips both production time and review.

## What's in it

Finished, approved static assets only. Drafts stay in the project folder they were made in.

| Belongs here | Doesn't belong here |
| :-- | :-- |
| Approved static ads, all ratios | Work in progress and unreviewed drafts |
| Approved images and photography | Video files, which go in the [video drive](/video-drive) |
| Display banners at fixed sizes | Logos and brand marks, which go in [brand assets](/brand-assets) |
| Diagrams, charts, and illustrations | Raw camera files with no export |
| Source files for approved assets | Copy documents, which go in the [copy drive](/copy-drive) |

```text
├── campaigns/

│       ├── google/
│       └── source/
├── evergreen/
│   ├── product-shots/
│   ├── team-and-office/
│   └── diagrams/
└── archive/
```

Campaign folders hold work made for one campaign. Evergreen holds assets that outlive any single campaign and get reused. Archive holds superseded assets kept for record.

## Naming

Every file follows the [file naming conventions](/file-naming-conventions). For a static ad, that means the asset type, descriptor, dimensions, date, version, and status:

`AD_q3-launch-hero_300x250_2027-09-15_v02_APPR.jpg`

The descriptor should match the creative name used in the [ad naming conventions](/ad-name-conventions), so an ad in a report can be traced to the file that produced it.

## Before you pull an asset

- **Check the status field in the file name.** A `v05` and an `APPR` file can both exist, and the newest version is not always the approved one.
- **Check the ratio against the placement.** See the [image and video specs](/image-and-video-specs). A crop is a reframe, not a resolution gain.
- **Check any usage limits.** Licensed stock, a customer logo, or a person's likeness may have an expiry or a restricted scope. Note these in the row above.

<Warning>
  Model releases, stock licenses, and customer logo permissions expire. An asset that was cleared for one campaign is not automatically cleared for the next one. Record the limit alongside the asset rather than relying on someone remembering it.
</Warning>
